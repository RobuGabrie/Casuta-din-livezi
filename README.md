# Căsuța din Livezi

Website for a family guesthouse, home kitchen (Punct Gastronomic Local) and lavender
field in Cacica, Bucovina.

- Plan: [docs/PLAN.md](docs/PLAN.md)
- Design rules and saved screens: [docs/design/](docs/design/RULES.md)

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Publish

See [docs/deploy.md](docs/deploy.md) (Hetzner + Coolify) and
[docs/notifications.md](docs/notifications.md) (WhatsApp and email for table requests).
